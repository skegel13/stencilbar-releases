# Stencilbar releases

This repository holds the release files for [Stencilbar](https://stencilbar.com), a macOS menu bar app that stores prompts and copies them to the clipboard.

It holds no source code. Each release has one file, `Stencilbar.zip`, which contains the signed and notarised app.

## Download

Get the newest version from the [latest release](https://github.com/skegel13/stencilbar-releases/releases/latest).

## Install

1. Unzip `Stencilbar.zip`.
2. Move `Stencilbar.app` to your Applications folder.
3. Open it. macOS asks once whether to open an app downloaded from the internet.

## Requirements

macOS 15 Sequoia or later.
